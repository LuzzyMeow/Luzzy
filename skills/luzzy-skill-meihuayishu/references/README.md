## 底本与置信度

- **周易经文**：底本为 ctext.org《周易》（《武英殿十三经注疏》本《周易正义》），64 卦全部逐卦核对；节、中孚、小过、既济、未济五卦经 anysearch 抓取确认。仅收经文（卦辞、爻辞、用九用六），不收《彖》《象》等传文。
- **梅花易数**：底本为用户提供之网络通行本（论坛转载，GB18030 编码）；以维基文库《梅花易數》三卷逐节交叉校验。校勘原则与全部改动清单见各卷文末「校勘记」：
  - 两本并同的文字**照录原文**，疑似讹误处以〔校注〕标明；
  - 明显讹字径改（如「泽天决」→「泽天夬」、「天风诟」→「天风姤」），逐条记入校勘记；
  - 底本脱句、脱节（如卷三「卦应」全节、卷二「三要灵应篇序」）据维基文库补全，补文以〔补〕标注。
- **历法数据**（lunarcal.py 内置农历位表与节气表，1900-2100）：转自社区通行历表 jjonline/calendar.js v1.0.3（含 2016 年 2033 闰月修正），经 34 项公开历表锚点校验（2020/2023/2024/2025/2026 春节、中秋、端午、十三年闰月、立春、冬至），`python3 lunarcal.py --selftest` 可随时复验；极早年（1900-1950）锚点较少，存疑时按 sources.md 联网万年历核对。

## 引用格式约定

解卦输出中引用内置资料时，标注格式统一为：

> 出处：`references/zhouyi-shangjing.md` · 泽火革 · 初九

或（联网验证时）：

> 出处：ctext.org/book-of-changes/ge/zhs · ䷰革 · 初九（与维基文库一致）

## 快速定位

- 查某卦第 N 爻爻辞：序 ≤30 → `zhouyi-shangjing.md`；序 >30 → `zhouyi-xiajing.md`；卦序→卦名映射见 `../gua_index.json`。
- 查体用生克断语：`meihua-juan2.md` → 「体用总诀」（乾/坤/震/巽/坎/离/艮/兑 各卦生体、克体之义）。
- 查分类占断（婚姻、求财、疾病、失物、出行…）：`meihua-juan2.md` → 体用生克篇之二十八占。
- 查应期（何日应验）：`meihua-juan3.md` → 「占卜克应之诀」。
- 查外应/十应：`meihua-juan2.md` → 三要灵应篇、十应诸论；`meihua-juan3.md` → 占卜十应诀。
