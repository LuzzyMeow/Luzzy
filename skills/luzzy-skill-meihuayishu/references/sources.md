# 高置信度资料源清单（回退步骤）

内置 `references/` 资料缺失、或用户要求在线核对时，按下列梯次检索。**每次解卦引文至少两个独立来源一致**；两源不一致时照录差异并告知用户。

## 使用规则

1. **顺序**：内置资料 → 第一/二梯次（双源）→ 第三梯次工具。禁止跳过内置资料直接联网。
2. **冲突处理**：经文两源不一致（异文）→ 在输出中并列照录，注明各自来源，不擅自择一。
3. **可信度排序**：ctext 武英殿本 ≈ 维基文库 > 一般国学网站 > 论坛/个人博客。论坛内容只作线索，不作引文依据。
4. **引用格式**：联网取材必须标注完整 URL 与访问所得文字；无法标注来源的文字不得作为卦爻辞引用。
5. 频率礼貌：ctext 抓取过频会触发验证码，按卦按需取页，勿批量爬取。
