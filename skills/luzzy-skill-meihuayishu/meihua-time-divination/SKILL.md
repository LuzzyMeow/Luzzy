# 梅花易数 · 时间起卦法 v2.2

计算全部委托给本技能家族根目录的 `lunarcal.py` + `engine.py`。
本 Skill 只负责：确定月法（默认农历月）+ 获取四要素 + 调用引擎。

## 原文

《梅花易数》卷一·年月日时起卦：
「年月日为上卦。年月日加时总数为下卦。又以年月日时总数取爻。如子年一数，丑年二数，直至亥年十二数。月如正月一数，直至十二月亦作十二数。日数如初一一数，直至三十日为三十数。以上年月日共计几数，以八除之，以余数作卦。如子时一数直至亥时十二数，就将年月日数加时之数，总计几数，以八除之，余数作下卦；以六除，余数作动爻。」

全文见 `../references/meihua-juan1.md`；书内范例「观梅占」（辰年十二月十七日申时，用农历月）见同文件象数易理篇之二。

## 月的取值：农历月（默认） vs 节气月（选项）

| 做法 | 规则 | 说明 |
|------|------|------|
| A. 农历月（默认） | 公历→农历，取农历月份数 | **忠于原文**：原文「正月一数直至十二月」，观梅占「十二月十二数」皆农历月 |
| B. 节气月 | 按交节时刻取地支月序（寅月=1…丑月=12） | 干支纪月逻辑的现代变通，非原文做法 |

处理原则：
- 用户未指明 → 用 A 法（农历月），忠于原文。
- 用户明确要求「按节气月/按干支月」→ 切换 B 法，并在结果中注明「此为变通，非原文月法」。
- 告知用户所用月法，一句话即可。

## 步骤

### 1. 确认日期时间

- 未提供日期时间 → 用当前时刻。
- 仅提供日期 → 时辰默认当前。
- 精确到分钟 → 严格按时辰表边界判断。

### 2. 调用 lunarcal.py 换算四要素

```bash
python3 <技能根目录>/lunarcal.py <年> <月> <日> <时> <分>
```

输出：年支(序数,名称)、农历月(序数,名称)、农历日(序数)、时支(序数,名称)、节气月(序数,名称)、立春界判定说明。
- A 法：月参数 = 农历月序数。
- B 法：月参数 = 节气月序数。
- lunarcal 覆盖 1900-2100 年；超出范围或对其输出存疑时，联网万年历核对农历日后再算。

### 3. 调用 engine.py 起卦

```bash
python3 <技能根目录>/engine.py time <年支数> <月数> <农历日> <时支数>
```

引擎自动完成：÷8取余（整除取8）→ 先天八卦 → 六十四卦 → 互卦 → 变卦 → 体用生克。

### 4. 输出结构化结果

向用户呈现引擎输出的本卦、动爻、互卦、变卦、体用、生克，并注明所用月法；解卦交回父 skill 流程。

## 重要规则

### 年以立春为界

立春（约 2 月 4 日）前属上一年地支。如 2026 年 1 月属乙巳年(巳=6)，2026-02-04 立春后属丙午年(午=7)。lunarcal.py 自动处理。
〔注〕原文无明文；立春分界为通行干支纪年做法，另有「正月初一换年」一派，用户坚持时从其说并注明。

### 时辰边界

| 时支 | 序数 | 时间 | | 时支 | 序数 | 时间 |
|------|------|------|---|------|------|------|
| 子 | 1 | 23:00-00:59 | | 午 | 7 | 11:00-12:59 |
| 丑 | 2 | 01:00-02:59 | | 未 | 8 | 13:00-14:59 |
| 寅 | 3 | 03:00-04:59 | | 申 | 9 | 15:00-16:59 |
| 卯 | 4 | 05:00-06:59 | | 酉 | 10 | 17:00-18:59 |
| 辰 | 5 | 07:00-08:59 | | 戌 | 11 | 19:00-20:59 |
| 巳 | 6 | 09:00-10:59 | | 亥 | 12 | 21:00-22:59 |

- 注意：09:19 = 巳时(6)，不是辰时。辰时到 08:59 为止。
- 〔注〕23:00-24:00 的「晚子时」换不换农历日，各家不一；本技能默认**不换日**（当日农历日+子时），用户提出异议时从其说并注明。

### 除法边界（引擎已实现，勿手动算）

- 总数 ÷8 整除 → 取 8（坤）；÷6 整除 → 取 6（上爻动）。

## 示例

**输入**：「观梅占那年辰年十二月十七日申时」（复现原书）
**执行**：四要素 = 年支辰(5)、农历十二月(12)、十七日(17)、申时(9) → `engine.py time 5 12 17 9` → 34÷8余2兑上、43÷8余3离下、43÷6余1初爻动 → 泽火革之初九变泽山咸，互见乾巽——与原书观梅占完全一致。

**输入**：「2026 年 2 月 3 日 23:30 起卦」
**执行**：lunarcal 判定 2026-02-03 在立春前 → 年支乙巳(6)；农历为乙巳年十二月十六；23:30 为子时(1)，晚子时不换日 → `engine.py time 6 12 16 1`。
