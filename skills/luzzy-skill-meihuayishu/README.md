## 🌟 项目简介

本项目是遵循 [Luzzy-Skill-Architect](../luzzy-skill-architect/) 规范构建的**梅花易数技能家族**（Skill Family），面向 AI Agent（如 ZCode / Claude 等）使用。用户对 Agent 说「帮我算一卦」「用我名字起卦」「报数 7 和 8」，Agent 即按本技能完成：**识别起卦方式 → 调用引擎计算 → 查内置经文引证 → 四层结构化解卦并标注出处**。

与网上常见的"口诀 + 拍脑袋"式实现不同，本项目的每一处计算与每一条引文都做到了**有出处、可验证**：

| 特性 | 说明 |
|------|------|
| 🧮 **自包含引擎** | `engine.py` + `lunarcal.py` 纯 Python 标准库（**零第三方依赖**），Python ≥ 3.8 即可运行，无需联网 |
| 📖 **经典原文内置** | 《梅花易数》三卷全文 + 《周易》64 卦经文（卦辞+爻辞+用九用六）全部离线内置，逐条标注底本与校勘记 |
| ✅ **原书占例回归** | 观梅占、牡丹占、借物占、西林寺牌额占、今日动静如何——五个原书占例作为回归用例，引擎输出与原文逐字吻合 |
| 🔬 **历法数据锚定** | 公历↔农历换算内置 1900–2100 年数据，经 34 项公开历表锚点自检（春节/闰月/节气） |
| 🌐 **三源交叉校对** | 全部文本经 ctext.org（武英殿十三经注疏本）、维基文库、高岛易断页三源联网交叉比对，修正与存录均有校勘记录 |
| 🧪 **可执行评测** | L4 评测件 `evals/` 可一键回归，防止文档示例与引擎输出脱节 |

> ⚠️ 卦象为传统术数文化参考，不构成任何现实决策建议。

## 🔢 三种起卦方式

| 方式 | 触发场景 | 计算规则（原文依据） | 命令 |
|------|----------|----------------------|------|
| **报数起卦** | 用户随口报 2–3 个数 | 2 数：动爻 =（数1+数2）÷6；3 数：动爻 = 数3÷6（原文物数占例加时法：第 3 参传 数1+数2+时辰数） | `engine.py number <n1> <n2> [n3]` |
| **时间起卦** | 指定日期时间或"现在" | 年支+月+日 ÷8 上卦，加时 ÷8 下卦，总数 ÷6 动爻（卷一·年月日时起例） | `lunarcal.py` → `engine.py time <年支> <月> <日> <时支>` |
| **姓名笔画起卦** | 提供姓名 | 按实际书写笔画（**非康熙笔画**）：2 字名首字上卦次字下卦；一字占楷书左为上右为下（卷一·字占） | `engine.py bihua <上笔画> <下笔画> [总数]` |

**时间起卦的两派月法**（默认 A 法，忠于原文）：

| 月法 | 规则 | 适用 |
|------|------|------|
| A. 农历月（默认） | 公历→农历，取农历月份数 | 忠于原文「正月一数直至十二月」与观梅占「十二月十二数」 |
| B. 节气月（选项） | 按 12 节交节日取地支月序（寅月=1） | 干支纪月的现代变通，非原文做法，输出时注明 |

**除法边界**（引擎已实现，禁止手动计算）：数 0 → 取 8（坤）；÷8 整除 → 8；÷6 整除 → 6（上爻动）；负数取绝对值；小数取整数部分。

## ⚙️ 引擎实现的原文规则

**先天八卦数**（卷一·周易卦数）：

> 乾一 · 兑二 · 离三 · 震四 · 巽五 · 坎六 · 艮七 · 坤八

**计算链条**（全部出自《梅花易数》卷一/卷二原文，文字内置可查）：

| 步骤 | 原文规则 | 引擎实现 |
|------|----------|----------|
| 取卦 | 卦以八除：过八数递除，余数作卦，整除取 8（坤） | `mod8()` |
| 取爻 | 爻以六除：以重卦总数除六，余数作动爻，整除取 6；「取爻当以时加之」 | `mod6()` |
| 互卦 | 去初爻与上爻，中间四爻分作两卦：三四五爻为**上互**、二三四爻为**下互**，上互为上卦、下互为下卦 | 位串切片 `bits[2:5]` / `bits[1:4]` |
| 变卦 | 动爻阳变阴、阴变阳 | 位串翻转 |
| 体用 | **动爻所在之卦为用卦**，另一卦为体卦（卷二·体用总诀；卷三「动者为用，静者为体」） | 动爻 1–3 爻→用为内卦，4–6 爻→用为外卦 |
| 生克 | 体宜受生比和，忌受克：用克体凶、体克用吉、体生用泄、用生体喜、比和百事顺遂 | 五行生克矩阵（金木水火土） |

[取卦] 下卦：加时（34+9）=43：43 ÷8 余3 → 离（火）

[动爻] 第1爻（初九）· 内卦

[互卦] 上互乾(金)·下互巽(木) → 天风姤 ䷫（第44卦）

## 🧮 实际起卦验算实录

以真实时刻 **2026-08-30 10:00（巳时）** 起一卦，全链路手工验算：

```text
第 1 步  lunarcal.py 2026 8 30 10 0
  → 年支 7(午) [立春界：2026-02-04 已过 → 丙午年]
  → 农历七月(7) 十八日(18)，时支 6(巳) [09:00–10:59]

第 2 步  engine.py time 7 7 18 6
  上卦：(7+7+18)=32 ÷8 = 4 整除 → 取 8 = 坤（土）   ← 「整除取8」边界规则
  下卦：32+6=38 ÷8 = 4 余 6 → 坎（水）
  动爻：38 ÷6 = 6 余 2 → 第 2 爻（九二）

第 3 步  引擎输出
  本卦：第 7 卦 地水师 ䷆（上坤土·下坎水）
  变卦：坤为地 ䷁（师六爻 010000，动二爻翻位 → 000000）
  互卦：地雷复 ䷗（上互 000 坤 · 下互 100 震）
  体用：体=坤(土)[外] 用=坎(水)[内]，体克用（耗）
  引文：师九二「在师中，吉，无咎。王三锡命」→ references/zhouyi-shangjing.md
```

手工复核：师卦六爻自下而上「阴阳阴阴阴阳」= 坎下坤上 ✓；二爻动在下卦→用=坎、体=坤 ✓；互卦取二三四爻「阳阴阴」= 震为下互、三四五爻「阴阴阴」= 坤为上互，上坤下震=地雷复 ✓。引擎、原文、手工三方一致。

## ⚠️ 使用须知

1. **文化参考**：梅花易数为传统术数文化，输出仅供文化体验与参考，不构成医疗、投资、法律等任何现实决策建议。技能内置强制提示。
2. **农历数据范围**：lunarcal 覆盖 **1900-01-31 至 2100-12-31**。极早年（1900–1950）公开锚点较少，对其输出存疑时按 `references/sources.md` 联网万年历复核后再用。
3. **两派约定**（技能内已注明，用户坚持时从其说）：年支默认**立春分界**（另有正月初一换年派）；23:00–24:00 晚子时默认**不换农历日**。
4. **报数起卦**为后人依据「卦以八除、爻以六除」的实践扩展，原文无专条——技能中已明确标注，并附原文物数占例加时法供选择。
5. **文本异文**：经典存在版本差异（如 遯/遁、巳日/已日），本仓库以 ctext 武英殿本为底本照录，异文均有记录；联网验证请遵循 `references/sources.md` 的双源规则。
