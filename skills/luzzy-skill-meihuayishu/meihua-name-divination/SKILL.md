# 梅花易数 · 姓名笔画起卦 v2.2

计算全部委托给本技能家族根目录的 `engine.py`。
本 Skill 只负责：笔画数取 + 字占规则 + 调用引擎。

## 原文

《梅花易数》卷一·字占：「凡见字数如停匀，即平分一半为上卦，一半为下卦。如字数不匀，即少一字为上卦，取天轻清之义，以多一字为下卦，取地重浊之义。」
一字占：「如楷书，则取其字画，以左为阳画，右为阴画。居左者看几数，取为上卦。居右者看几数，取为下卦。」
全文与「西林寺牌额占」等字画占例见 `../references/meihua-juan1.md`。

## 繁简与康熙：核心规则

| 场景 | 用什么标准 | 例子 |
|------|-----------|------|
| 梅花易数字占（本 skill） | 用户输入什么字，就数什么字的实际笔画。不自动转换繁简。 | 「杨」→ 7 画；「楊」→ 13 画 |
| 姓名学·五格剖象（与本 skill 无关） | 一律转繁体 + 康熙字典归部 | 「杨」→ 13 画 |

**结论：按实际书写笔画。** 原文「取其字画」——取眼前这个字实际写出来的笔画数。

### 繁简处理细则

1. 用户输入简体 → 按简体数，不自动转繁体。
2. 用户输入繁体 → 按繁体数，不自动简化。
3. 未明确 → 按输入文字直接数。
4. 用户坚持传统繁体 → 请用户自行转繁体后再输入。

## 易错字速查

| 字 | 正确笔画 | 常见错误 | 原因 |
|----|---------|------|------|
| 王 | **4** | 5 | 康熙归玉部加 1 |
| 杨 | **7** | 13 | 自动转繁体 |
| 扌 | **3** | 4 | 康熙按「手」算 |
| 氵 | **3** | 4 | 康熙按「水」算 |
| 忄 | **3** | 4 | 康熙按「心」算 |
| 阝(左) | **2** | 3 | 康熙按「阜」算 |
| 阝(右) | **2** | 3 | 康熙按「邑」算 |
| 艹 | **3** | 4-6 | 康熙按「艸」算 |

> 一句话：看到几笔就是几笔。不要想它「本来应该」是什么部首。

## 步骤

### 1. 逐字数笔画

确认汉字形式（简/繁），按实际书写数每字笔画。对笔画数有疑问时，用汉典 zdic.net 或国学大师逐字核对，不得凭感觉。

### 2. 按字数分配上下卦

| 总字数 | 规则 | 示例 |
|--------|------|------|
| 1 字 | 楷书取偏旁字画：**居左者为上卦，居右者为下卦**（原文一字占）。「智」→ 左「知」8 画为上卦(坤)，右「日」4 画为下卦(震)，全画 12÷6 整除取 6 上爻动 → 地雷复。非左右结构字按全字笔画 ÷8 分上下（变通，注明） |
| 2 字 | 第一字为上卦，第二字为下卦（两仪平分） | 「杨智」→ 上杨(7艮)下智(12÷8余4震) |
| 3 字 | 一字为上卦，二字为下卦（三才） | 「王梓懿」→ 上王(4震)下梓懿(11+22=33÷8余1乾) |
| 4 字 | 前二字上卦，后二字下卦（四象平分） | |
| 5 字 | 二字上卦，三字下卦（五行） | |
| 6/8/10 字 | 平分上下 | |
| 7 字 | 三字上卦，四字下卦 | |
| 9 字 | 四字上卦，五字下卦 | |
| 11 字+ | 平分；不匀则少一字为上卦（天轻清） | |

〔注〕原文四字以上「不必数画数，只以平仄声音调之」（平1上2去3入4）。入声须按古音判断，今音已并入四声；姓名占通常仍按字画数取，两法并用时注明「声调法系原文旧例」。

**注意**：体用不由「谁的名字」决定，由动爻位置决定（engine 自动输出）。

### 3. 调用引擎（严禁手动计算）

```bash
python3 <技能根目录>/engine.py bihua <上卦总笔画> <下卦总笔画> [<动爻数>]
```

- 两字名及多字名：动爻 =（上+下总笔画）÷6，引擎自动算，不必传第三参。
- 一字占：动爻 = 全画数 ÷6；如需指定传第三参。
- 引擎自动完成：÷8取余 → 八卦 → 六十四卦 → 互卦 → 变卦 → 体用生克。

### 4. 输出结构化结果

呈现本卦、动爻、互卦、变卦、体用、生克；解卦交回父 skill 流程（四层判断+出处标注）。

## 示例

**输入**：「用名字『杨智』算一卦」
**执行**：杨=7画，智=12画 → `engine.py bihua 7 12` → 7=艮上、12÷8余4=震下、动爻=19÷6余1 → 艮上震下=山雷颐，初爻动变山地剥 → 引颐卦初九爻辞「舍尔灵龟，观我朵颐，凶」与颐卦卦辞解之。（〔易错〕先天数 7=艮、2=兑，勿混。）

**输入**：「『楊』字单字占」
**执行**：确认繁体 13 画。「楊」左右结构：左「木」4 画为上卦(震)，右「昜」9 画为下卦(9÷8余1乾)，全画 13÷6余1 初爻动 → 震上乾下=雷天大壮 → 按流程解卦。
