# 梅花易数 · 报数起卦法 v2.2

计算全部委托给本技能家族根目录的 `engine.py`。
本 Skill 只负责：参数校验 + 调用引擎 + 返回结构化结果。

## 原文依据与变通说明

《梅花易数》卷一（见 `../references/meihua-juan1.md`）：
- 「乾一兑二离三震四巽五坎六艮七坤八」（先天八卦数）
- 「卦以八除」——数 ÷8，整除取 8（坤）
- 「爻以六除」——数 ÷6，整除取 6（上爻动），「取爻当以时加之」

〔注〕原文无「报数占」专条；报数起卦是后人依据上两条除法规则的实践扩展。取动爻存在两派：
1. **本技能默认**：2 数 →（数1+数2）÷6；3 数 → 数3÷6。
2. **原文物数占例法**：（上卦数+下卦数+时辰数）÷6——更合「取爻当以时加之」。用时先取时辰序数（lunarcal.py 或时辰表），再把**总数（数1+数2+时辰数）作为第 3 参**传入引擎（3 数语义即「第 3 数÷6 取动爻」，总数÷6 恰为加时法），并在结果注明「动爻按原文物数占例加时法」。

## 步骤

### 1. 确认用户已想好所问之事

「不动不占，不因事不占。」报数前必须心念集中。若用户未说明所问何事，先提示，再继续。

### 2. 接收数字

- 2 个数：数1=上卦，数2=下卦，动爻=（数1+数2）÷6
- 3 个数：数1=上卦，数2=下卦，数3÷6=动爻
- 1 个数：该数为上卦，当前时辰数为下卦（配合 lunarcal.py），（上+时）÷6 取动爻
- 4 个数及以上：前两数上下卦，其余各数之和÷6=动爻（实践扩展，注明）

### 3. 调用引擎（严禁手动计算）

```bash
python3 <技能根目录>/engine.py number <数1> <数2> [<数3>]
```

引擎自动完成：÷8取余（整除取8）→ 先天八卦 → 六十四卦查表 → 互卦 → 变卦 → 体用生克。

### 4. 输出结构化结果

呈现本卦、动爻、互卦、变卦、体用、生克；解卦交回父 skill 流程。

## 边界情况

| 情况 | 处理 |
|------|------|
| 数字为 0 | 按 0 处理 → ÷8 取 8 = 坤 |
| 负数 | 取绝对值 |
| 小于 8 | 不除，直接用该数作卦 |
| 整除 ÷8 | 余数取 8 = 坤 |
| 整除 ÷6 | 余数取 6 = 上爻动 |
| 小数 | 取整数部分 |
| 数字特别大 | 直接交给引擎，勿自行缩小 |

## 示例

**输入**：「报数 7 8，问合作」
**执行**：确认问题 → `engine.py number 7 8` → 7=艮上、8=坤下、动爻=15÷6余3 → 山地剥三爻动变艮，互坤坤，体艮用坤比和 → 交回父 skill 解卦（剥六三爻辞「剥之，无咎」等）。

**输入**：「报 3、5、2」
**执行**：`engine.py number 3 5 2` → 3=离上、5=巽下、动爻=2（第2爻）→ 火风鼎二爻动变火山旅 → 交回父 skill。
